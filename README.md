# Volunteer App - تطبيق الفريق التطوعي

تطبيق لتسجيل بيانات العائلات المحتاجة خلال الجولات الميدانية، مع إمكانية البحث والتصدير إلى Excel.

## الفكرة
- جمع بيانات العائلات: اسم رب الأسرة، الزوجة، أفراد العائلة، أرقام التواصل، مكان التهجير، مكان الإقامة الحالي، نوع المنزل، وجود معيل، الاحتياجات، التلبية، والملاحظات.
- واجهة مستخدم بسيطة باللون الأبيض والأخضر.
- إمكانية البحث بالعائلات حسب: اسم رب الأسرة، اسم الزوجة، أو التلبية التي سيتم تقديمها.
- حفظ البيانات محليًا دون الحاجة للإنترنت.
- تصدير البيانات إلى Excel عند الحاجة.

## المتطلبات
- Flutter SDK >=2.19
- مكتبات: `excel`, `path_provider`
- IDE: VS Code أو Android Studio
